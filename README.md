# printing-sitio

El sitio público de Printing Solutions: la portada y el aviso de privacidad. HTML y CSS sin
servidor, con la paleta azul marino de la app. Se publica con GitHub Pages desde `main`.

- `index.html`: qué es la red, cómo funciona y el contacto.
- `privacidad.html`: el aviso de privacidad (lo que guarda printing-api).
- `estilos.css`: los colores del modo oscuro de printing-web.

Para verlo en local: `py -m http.server 3300`.
